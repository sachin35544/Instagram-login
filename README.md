A clean and responsive clone of the Instagram login page built using only HTML and CSS.

## Features

- Responsive layout for different screen sizes
- Instagram-inspired login and sign-up UI
- Stylish form fields and buttons
- Mobile-friendly design
- Pure HTML and CSS implementation

## Run Locally

1. Clone the repository
2. Open `index.html` in your browser
3. Or use a local live preview extension such as VS Code Live Server

```bash
git clone https://github.com/sachin35544/Instagram-login.git
cd Instagram-login
```
